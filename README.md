# Demonstrateur

Démonstrateur d'un assistant conversationnel qui aide un agent à rédiger la fiche d'expression de besoin d'une
demande d'évolution du système d'information, simule la décision du chef de service, puis produit la fiche validée au
format Word.

Données fictives uniquement : aucune identité, demande ou décision réelle.
